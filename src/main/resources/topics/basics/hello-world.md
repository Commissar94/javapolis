# Hello World - Первая программа

Добро пожаловать в мир Java программирования! Давайте начнем с самого простого - программы "Hello World".

## Что такое Hello World?

Программа "Hello World" - это традиционная первая программа, которую пишут начинающие программисты. Она просто выводит на экран текст "Hello, World!".

## Код программы

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## Разбор кода

Давайте разберем каждую часть:

- `public class HelloWorld` - объявление публичного класса с именем HelloWorld
- `public static void main(String[] args)` - главный метод программы
- `System.out.println()` - команда для вывода текста на экран

## Как запустить

1. Сохраните код в файл `HelloWorld.java`
2. Скомпилируйте: `javac HelloWorld.java`
3. Запустите: `java HelloWorld`

## Результат

После запуска вы увидите:
```
Hello, World!
```
