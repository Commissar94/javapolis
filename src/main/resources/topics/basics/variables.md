# Переменные в Java

Переменные - это основа любого программирования. Давайте разберем, что это такое и как их использовать.

## Что такое переменная?

Переменная - это контейнер для хранения данных в памяти компьютера. У каждой переменной есть:
- **Имя** - как мы обращаемся к переменной
- **Тип** - какой вид данных она хранит
- **Значение** - что именно хранится в переменной

## Объявление переменных

В Java переменные объявляются так:

```java
тип_данных имя_переменной;
```

## Основные типы данных

### Целые числа
```java
int age = 25;           // целое число
long population = 8000000000L;  // большое целое число
```

### Дробные числа
```java
double price = 19.99;   // дробное число
float temperature = 36.6f;  // дробное число с меньшей точностью
```

### Символы и строки
```java
char grade = 'A';        // один символ
String name = "Иван";    // строка текста
```

### Логические значения
```java
boolean isStudent = true;    // true или false
boolean isWorking = false;
```

## Пример программы

```java
public class VariablesExample {
    public static void main(String[] args) {
        // Объявляем переменные
        String firstName = "Анна";
        String lastName = "Петрова";
        int age = 30;
        double height = 1.75;
        
        // Используем переменные
        System.out.println("Имя: " + firstName);
        System.out.println("Фамилия: " + lastName);
        System.out.println("Возраст: " + age + " лет");
        System.out.println("Рост: " + height + " м");
        
        // Изменяем значение переменной
        age = 31;
        System.out.println("В следующем году будет: " + age + " лет");
    }
}
```

## Правила именования

1. **Имена должны начинаться с буквы, подчеркивания или знака доллара**
2. **Могут содержать буквы, цифры, подчеркивания и знаки доллара**
3. **Регистр имеет значение** - `age` и `Age` это разные переменные
4. **Нельзя использовать ключевые слова Java**

{style="warning"}
Избегайте однобуквенных имен переменных (кроме счетчиков в циклах). Используйте понятные имена!
{/style}

## Константы

Константы - это переменные, значение которых нельзя изменить:

```java
final double PI = 3.14159;
final String COMPANY_NAME = "JavaCorp";
```

{style="info"}
Используйте `final` для переменных, которые не должны изменяться после инициализации.
{/style}
