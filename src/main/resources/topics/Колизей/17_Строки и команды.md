# «1» — это команда, а не число

Игрок ввёл `1`. Мы получили строку. Теперь сравним её с текстом нужной команды.

```java
String action = "1";
System.out.println(action.equals("1")); // true
System.out.println(action.equals("2")); // false
```

Для сравнения содержимого строк используй `equals`. Оператор `==` у ссылочных типов проверяет, указывают ли ссылки на один объект. На строковых литералах он иногда случайно даёт ожидаемый ответ из-за переиспользования строк. Переносить это ожидание на ввод игрока нельзя.

## Немного терпимости к пробелам

```java
String action = " 1 ";
action = action.trim();
System.out.println(action.equals("1")); // true
```

`trim()` возвращает строку с удалёнными по краям символами с кодом не больше U+0020, включая обычный пробел и табуляцию. Это не универсальное удаление всех возможных пробельных символов Unicode. Для простого консольного меню этого достаточно.

Строки неизменяемы: вызов `action.trim();` сам по себе не перепишет переменную. Нужен результат: `action = action.trim();`. Внутренний пробел в `"Сэр Баг"` этот метод не убирает.

Пустую строку проверяем так:

```java
String name = "   ";
name = name.trim();
if (name.isEmpty()) {
    name = "Спартак";
}
System.out.println(name);
```

`isEmpty()` отвечает, равна ли длина нулю. До `trim()` строка из трёх пробелов не пуста; после — пуста. `null` не является пустой строкой, и вызов метода на `null` приведёт к ошибке. При успешном `nextLine()` получаем настоящую строку, поэтому в нашем вводе это не проблема.

## Разрешаем только известное

Для меню нужны строки `"0"`, `"1"`, `"2"`, `"3"`. Всё остальное — неизвестная команда. Мы не превращаем `"01"` в `"1"`, не извлекаем цифру из `"атака 1"` и не пытаемся угадать намерение игрока. Простое правило легче объяснить и проверить.

{quiz}
После String action = " 2 "; выполнен только вызов action.trim(); без присваивания. Чему равно action.equals("2")?
- true
+ false
{/quiz}

Практика: прочитай строку через `Scanner`, обрежь края и при `equals("1")` напечатай «Атака». В остальных случаях — «Неизвестная команда». Проверь `1`, ` 1 `, `01`, пустую строку и `меч`.

Проверка поведения: [Oracle: String](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html#equals(java.lang.Object)).
