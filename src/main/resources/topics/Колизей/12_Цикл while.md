# while: ещё один раунд

Один удар работает. Чтобы сделать бой, можно вставить тот же код ещё десять раз. Но что, если противник выживет и после десятого? Разработчик выходит на арену с Ctrl+C и Ctrl+V? Нет, берём цикл.

```java
int trainingHits = 0;
while (trainingHits < 3) {
    trainingHits++;
    System.out.println("Тренировочный удар: " + trainingHits);
}
```

Увидишь удары 1, 2 и 3. `while` сначала проверяет условие. Если оно истинно, выполняет тело; затем проверяет условие заново. При ложном условии идёт дальше после цикла. Если условие ложно с самого начала, тело не выполнится ни разу.

## Что меняется между проверками

| Проверка | `trainingHits` | Условие `< 3` | Действие |
|---|---|---|---|
| Первая | 0 | `true` | Увеличить до 1, напечатать |
| Вторая | 1 | `true` | Увеличить до 2, напечатать |
| Третья | 2 | `true` | Увеличить до 3, напечатать |
| Четвёртая | 3 | `false` | Выйти |

Удали `trainingHits++` — и условие не перестанет быть истинным. Получится бесконечный цикл. Останови его кнопкой Stop в IDE; это не повод перезагружать компьютер.

## Переносим на арену

Условие боя: `heroHealth > 0 && enemyHealth > 0`. Внутри уменьшается здоровье бойцов. Начальные характеристики объявляем **до цикла**. Если внутри каждый раз делать `int enemyHealth = 45`, противник будет возрождаться быстрее, чем мы его бьём.

Счётчик раундов тоже создаём до цикла и увеличиваем в начале каждого раунда. Временный урон можно объявлять внутри: он нужен только для текущего прохода.

Важная деталь: `while` проверяет условие только на входе в очередной проход. Если враг погиб посередине тела, оставшиеся инструкции сами не отменятся. Поэтому внутри по-прежнему нужна проверка перед его ответом. В следующей главе про управление циклом научимся выходить сразу.

Практика: напечатай раунды от 1 до 4, затем замени начальное значение счётчика на 4 и предскажи результат при условии `< 4`. Вывода не будет. После этого объясни словами, какая переменная в твоём бою приближает завершение цикла.
