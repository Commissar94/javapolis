# Консоль: голос нашего гладиатора

Программа может правильно посчитать здоровье и молча закрыться. С точки зрения Java всё прекрасно. Игрок, правда, ничего не понял.

`System.out.println(...)` выводит значение и переводит курсор на следующую строку. `System.out.print(...)` печатает без такого перевода.

```java
String heroName = "Спартак";
int health = 100;
System.out.println("Гладиатор: " + heroName);
System.out.println("Здоровье: " + health);
System.out.print("Арена ");
System.out.println("открыта!");
```

Результат:

```text
Гладиатор: Спартак
Здоровье: 100
Арена открыта!
```

## Что делает плюс

Когда один из операндов `+` — строка, получается склейка текста. Значение `health` превращается в текст для вывода, но **тип самой переменной остаётся `int`**. В строку попадает текущее значение, а не имя переменной.

Сравни:

```java
System.out.println("Урон: " + 10 + 5);
System.out.println("Урон: " + (10 + 5));
```

Первая строка выведет `Урон: 105`, вторая — `Урон: 15`. Операции `+` здесь выполняются слева направо; скобки во втором случае заставляют сначала посчитать сумму. Арифметику подробнее разберём после первого этапа.

Пробелы тоже часть текста. В `"Герой:" + heroName` Java не догадается добавить пробел за тебя.

## Как напечатать кавычки

Внутри строкового литерала кавычку записывают как `\"`, обратную косую черту — как `\\`, перевод строки — как `\n`.

```java
System.out.println("Гладиатор по прозвищу \"Компилятор\"");
System.out.println("Первый бой\nВторой бой");
```

Пока вполне можно использовать несколько `println`, если это понятнее. Чем короче программа, тем не обязательно лучше обучение.

{quiz}
Что выведет System.out.println("Броня: " + 2 + 3)?
- Броня: 5
+ Броня: 23
- Программа не скомпилируется.
{/quiz}

Практика: выведи две строки — `Гладиатор: твоё имя` и `Здоровье: 100`. Имя и здоровье должны храниться в переменных. Измени имя только в объявлении и запусти снова. Если вывод изменился, переменные работают на тебя.
