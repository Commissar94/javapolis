# break и continue: покидаем раунд с достоинством

Враг получил последний удар. До следующей проверки `while` ещё несколько строк, включая его ответ. Хороший момент сказать: «Всё, заканчиваем».

```java
int enemyHealth = 8;
while (enemyHealth > 0) {
    enemyHealth = enemyHealth - 10;
    if (enemyHealth <= 0) {
        enemyHealth = 0;
        System.out.println("Противник повержен.");
        break;
    }
    System.out.println("Противник отвечает.");
}
System.out.println("Бой завершён.");
```

`break` завершает ближайший охватывающий цикл. После него выполнение продолжается за циклом; вся программа не прекращается. Ответа противника здесь не будет.

## Пропустить один проход

`continue` оставляет цикл работающим, но пропускает остаток текущего прохода. В `while` управление возвращается к проверке условия.

```java
int number = 0;
while (number < 3) {
    number++;
    if (number == 2) {
        continue;
    }
    System.out.println(number);
}
```

Вывод: 1 и 3. Заметь, что счётчик увеличивается **до** `continue`. Если увеличение стоит только в пропущенной части, цикл может застрять на одном значении.

Позже игрок введёт неизвестную команду. Можно вывести сообщение и сделать `continue`: враг не атакует за опечатку, а игрок получает новое приглашение.

## Где их использовать в игре

| Событие | Что нужно |
|---|---|
| Противник повержен | `break`, бой окончен |
| Игрок выбрал выход | Запомнить выход и сделать `break` |
| Игрок ввёл ерунду | Сообщение и `continue`, бой продолжается |
| Закончилось обычное действие | Дать врагу ответить, перейти к следующему ходу |

Не ставь `continue` после каждой атаки: так можно нечаянно постоянно пропускать ход врага. Он оценит, но проверяющий — вряд ли.

{quiz}
Что делает break внутри while, если внутри него нет других циклов?
- Завершает всю программу.
+ Выходит из этого while и продолжает выполнение после него.
- Пропускает только текущий проход и начинает следующий.
{/quiz}

Практика: выполни первый пример и убедись, что строки «Противник отвечает» нет. Измени исходное здоровье на 18: теперь один ответ появится, после второго удара бой закончится.
