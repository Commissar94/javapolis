# Этап 3. Автоматический бой

Теперь нажимаем Run один раз и смотрим целый бой. Игрок пока зритель. Зато разработчик уже ты.

**Основа:** возьми второй этап и оберни обмен ударами в `while`. Сохраняем правила минимального урона, нулевой границы здоровья и отсутствия ответа после смерти. Для этого этапа меняем баланс:

| Параметр | Герой | Противник |
|---|---|---|
| Начальное здоровье | 100 | 45 |
| Броня | 2 | 3 |
| Атака до вычитания брони | От 12 до 18 включительно | От 8 до 12 включительно |

## Что реализовать

1. Создай здоровье, броню и `round = 0` до цикла.
2. Продолжай бой, пока оба бойца живы.
3. В начале прохода увеличь `round` и выведи номер.
4. Сгенерируй атаку героя, примени броню врага и минимум урона 1.
5. Обнови здоровье врага, ограничь нулём, выведи урон и здоровье.
6. Если враг повержен — выйди из цикла до его ответа.
7. Иначе аналогично проведи его атаку и выведи состояние героя.
8. После цикла напечатай победу или поражение, число раундов и итоговое здоровье.

## Как проверить без гадания

Сначала временно зафиксируй атаку героя на 12, противника на 8. Тогда урон будет 9 и 6. Ожидаемые состояния после проходов:

| Раунд | HP противника | HP героя |
|---|---|---|
| 1 | 36 | 94 |
| 2 | 27 | 88 |
| 3 | 18 | 82 |
| 4 | 9 | 76 |
| 5 | 0 | 76 — ответа уже нет |

Затем верни случайность. При основных настройках бой завершится победой за 3–5 раундов. Итоговое здоровье героя будет от 60 до 88: каждое ответное попадание снимает 6–10 HP, а ответов от двух до четырёх.

Дополнительные проверки делай отдельно: здоровье героя 1 должно привести к поражению в первом раунде, а здоровье врага 1 — к победе без ответного удара. Нигде не печатается отрицательное здоровье. Повышение брони не должно делать урон отрицательным или нулевым.

{collapsible="true"}
Подсказка к самой частой ошибке
{/collapsible}

Не объявляй начальное здоровье заново внутри `while`. Снаружи живёт состояние всего боя, внутри — временные числа текущего удара. И не рассчитывай, что условие цикла прервёт выполнение сразу после смерти врага: для этого нужна отдельная проверка с `break`.

{/collapsible}

**Готово, когда:** бой всегда заканчивается при допустимых положительных начальных характеристиках, после смерти никто не бьёт, фиксированный сценарий совпадает с таблицей. Верни настройки задания и сохрани этап 3. На следующем этапе зритель получит пульт управления.


{collapsible="true"}
Разбор и один из вариантов решения
{/collapsible}

```java
public class Main {
    public static void main(String[] args) {
        int heroHealth = 100;
        int heroArmor = 2;
        int enemyHealth = 45;
        int enemyArmor = 3;
        int round = 0;

        while (heroHealth > 0 && enemyHealth > 0) {
            round++;
            System.out.println("Раунд: " + round);
            int attack = 12 + (int) (Math.random() * 7);
            int damage = attack - enemyArmor;
            if (damage < 1) {
                damage = 1;
            }
            enemyHealth = enemyHealth - damage;
            if (enemyHealth < 0) {
                enemyHealth = 0;
            }
            System.out.println("Урон героя: " + damage);
            System.out.println("Здоровье противника: " + enemyHealth);
            if (enemyHealth == 0) {
                break;
            }

            int enemyAttack = 8 + (int) (Math.random() * 5);
            int enemyDamage = enemyAttack - heroArmor;
            if (enemyDamage < 1) {
                enemyDamage = 1;
            }
            heroHealth = heroHealth - enemyDamage;
            if (heroHealth < 0) {
                heroHealth = 0;
            }
            System.out.println("Урон противника: " + enemyDamage);
            System.out.println("Здоровье героя: " + heroHealth);
        }

        if (heroHealth > 0) {
            System.out.println("Победа!");
        } else {
            System.out.println("Поражение.");
        }
        System.out.println("Раундов: " + round);
        System.out.println("Итоговое здоровье: " + heroHealth);
    }
}
```
