# Переменные: дадим здоровью имя

Можно печатать число `100` в десяти местах. А потом менять его на `120` в девяти и весь вечер искать десятое. Есть способ приятнее: назовём значение.

```java
int health = 100;
System.out.println(health);
health = 80;
System.out.println(health);
```

Получим сначала `100`, потом `80`. `int` — тип, `health` — имя, `100` — начальное значение. `=` присваивает значение справа переменной слева. Точка с запятой завершает эту инструкцию.

Первый раз переменную **объявляем** с типом. Потом меняем значение без повторного `int`. В одном блоке нельзя ещё раз объявить `int health`, если это имя уже занято. И менять тип на ходу нельзя: `health = "вроде жив";` не скомпилируется.

## Сначала значение, потом использование

Переменные внутри `main` — локальные. Перед чтением им необходимо присвоить значение. Они не получают автоматически ноль только потому, что нам так удобно.

Не компилируется:

```java
int health;
System.out.println(health);
```

Работает:

```java
int health;
health = 100;
System.out.println(health);
```

Пока проще сразу писать `int health = 100;`.

## Имена для человека

Выбираем `heroHealth`, `enemyArmor`, `potions`, а не `a`, `b`, `aboba2`. Для обычных переменных используем `lowerCamelCase`: первое слово с маленькой буквы, следующие — с большой. Это соглашение, а не магическая способность Java.

Регистр важен: `health` и `Health` — разные имена. Имя не может начинаться с цифры, содержать пробелы или совпадать с ключевым словом вроде `int`.

```java
int health = 100;
int previousHealth = health;
health = 70;
System.out.println(previousHealth); // 100
System.out.println(health);         // 70
```

Для примитивов присваивание копирует значение. `previousHealth` не превращается в провод, по которому автоматически прилетают все будущие изменения `health`.

## Комментарии

`//` начинает комментарий до конца строки. Java его не выполняет. Пиши там причину решения, если без неё трудно разобраться. Комментарий `// здоровье` возле `health` мало что добавляет; `// герой начинает каждый новый турнир с полным здоровьем` уже полезнее.

Практика: объяви имя, здоровье и броню. Выведи здоровье, поменяй его на 65 и выведи ещё раз. Удали начальное значение и посмотри на сообщение IDE, затем исправь. Ошибка здесь — запланированная экскурсия, а не катастрофа.

Основание: [Oracle: локальные переменные и начальные значения](https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.12.5).
