# Литералы: буквально значения

За непонятным словом скрывается простая вещь: **литерал — запись значения прямо в коде**. `100`, `true`, `'C'`, `"Спартак"` — литералы. А `health` — имя переменной, не литерал. До переменных скоро доберёмся.

![Буквально](litterally_1.gif)

## Что мы можем написать

| Запись | Что означает |
|---|---|
| `100` | Целое число; эта запись имеет тип `int` |
| `3_000_000_000L` | Целое число типа `long`; `L` важна для такого большого значения |
| `1.5` | Дробное число типа `double` |
| `1.5f` | Дробное число типа `float` |
| `'C'` | Значение `char`, один кодовый элемент UTF-16 |
| `"Спартак"` | Строка `String` |
| `true`, `false` | Логические значения |
| `null` | Отсутствие ссылки на объект; это не ноль и не пустая строка |

Не трать силы на заучивание таблицы. Для первого этапа нужны целые числа, строки и пара простых флагов.

Дробную часть записываем **через точку**: `1.5`. Запятая `1,5` в Java означает совсем другое. Подчёркивания между цифрами нужны для читаемости: `1_000` и `1000` дают одно и то же число. У целого литерала суффикс `L` выбирает тип `long`; без суффикса наши небольшие десятичные литералы имеют тип `int`.

Строго говоря, в `-5` минус — отдельный оператор перед литералом `5`. В разговоре часто говорят «отрицательный литерал», но устройство языка чуть аккуратнее этой фразы.

## Кавычки имеют значение

```java
System.out.println(100);
System.out.println("100");
System.out.println('C');
System.out.println("Спартак");
```

Первые две строки выглядят в консоли одинаково. Но число можно складывать как число, а текст `"100"` сам по себе числом не становится. Одинарные кавычки используем для `char`, двойные — для строки. Запись `'Спартак'` не компилируется.

`char` не гарантирует хранение любого видимого символа: например, многим эмодзи нужны два элемента UTF-16. Для имён и обычного текста берём `String` и не устраиваем гладиатору экзамен по Unicode.

Какая запись является строковым литералом?
- 'A'
+ "Арена"
- heroName
- 100
{/quiz}

## Маленькая практика

Выведи имя героя строкой, его здоровье числом и букву ранга. Затем поменяй имя на `"Кнопкодав"`. Если всё заработало, ты уже умеешь менять содержание программы. Следующий шаг — перестать разбрасывать значения по коду.

Проверка деталей: [Oracle: литералы, JLS §3.10](https://docs.oracle.com/javase/specs/jls/se21/html/jls-3.html#jls-3.10).
