# Примитивы: какое значение сюда поместится

У Java есть восемь примитивных типов. Тип определяет, какие значения можно хранить и какие действия с ними допустимы. Хранить имя героя в `int` не получится. Даже если герой согласен называться 42.

![Восемь типов](bts.gif)

| Тип | Значения и назначение |
|---|---|
| `byte` | Целые от −128 до 127 |
| `short` | Целые от −32 768 до 32 767 |
| `int` | Целые от −2 147 483 648 до 2 147 483 647 |
| `long` | Целые от −9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 |
| `float` | Дробные числа формата binary32, обычно около 6–7 значащих десятичных цифр |
| `double` | Дробные числа формата binary64, обычно около 15–16 значащих десятичных цифр |
| `char` | Кодовый элемент UTF-16: от 0 до 65 535 |
| `boolean` | Только `true` или `false` |

Диапазоны целых включают обе границы. У `byte`, `short`, `int`, `long` соответственно 8, 16, 32 и 64 бита для значения; у `char` — 16. Это не обещание, что переменная вместе со всем окружением займёт ровно столько памяти. Размер хранения `boolean` язык одной универсальной цифрой не фиксирует.

## Что выбрать для игры

Для здоровья, урона, номера боя и зелий берём `int`: его диапазона здесь хватает с огромным запасом. Более узкие типы имеют свои применения, но для нашего героя экономить несколько бит смысла нет. `long` понадобится, когда реальный диапазон целых выйдет за пределы `int`.

`float` и `double` могут хранить отрицательные значения, ноль и положительные значения. Многие десятичные дроби представляются приблизительно. Поэтому `0.1 + 0.2` не обязано дать в точности `0.3`. Для игровых коэффициентов это часто допустимо; точный денежный расчёт — отдельная тема. У нас здоровье будет целым, чтобы не отвлекаться.

## А строки и null?

`String` — ссылочный тип, **не девятый примитив**. Мы используем его для текста:

```java
String heroName = "Спартак";
int health = 100;
boolean champion = false;
```

Это объявления переменных; следующая глава разберёт каждую часть записи.

`null` можно присвоить переменной ссылочного типа, например `String`, но нельзя присвоить `int`, `boolean` или другому примитиву. `String name = null;` и `String name = "";` — разные состояния: в первом строки нет, во втором строка есть, но она пустая. В нашей игре намеренно используем настоящие строки и без `null` прекрасно проживём.

{quiz}
Выбери все верные утверждения.
+ Здоровье 100 удобно хранить в int.
- String — примитивный тип.
- int может хранить null.
+ boolean имеет значения true и false.
{/quiz}

Для проверки себя: какой тип возьмёшь для имени, количества побед и признака «турнир завершён»? Ответы: `String`, `int`, `boolean`. Если ты их выбрал, таблица уже начала окупаться.

Точные правила: [Oracle: типы и значения, JLS §4.2–4.3](https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2).
