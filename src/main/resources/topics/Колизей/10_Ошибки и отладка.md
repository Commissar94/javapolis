# Красный текст — это сообщение, а не приговор

Программа не запустилась. Бывает. Первый полезный навык разработчика — выяснить, что именно произошло, прежде чем переписывать всё целиком.

Есть три разные ситуации:

| Ситуация | Пример | Куда смотреть |
|---|---|---|
| Ошибка компиляции | Не закрыта кавычка, неизвестное имя | Первая ошибка компилятора и строка перед ней |
| Ошибка во время выполнения | Целочисленное деление на ноль | Сообщение исключения и строка твоего кода |
| Логическая ошибка | Броня лечит противника | Значения переменных и порядок действий |

Если первая ошибка сломала разбор программы, последующие могут быть её последствиями. Начни с первой, снова запусти и только потом разбирай остальные.

## Где видна переменная

```java
int health = 100;
if (health > 0) {
    int bonus = 5;
    System.out.println(bonus);
}
System.out.println(health);
```

`health` объявлена во внешнем блоке и доступна внутри `if`. `bonus` объявлена внутри и после закрывающей скобки этого блока уже недоступна. Попытка добавить после блока `System.out.println(bonus);` не скомпилируется.

Если значение нужно после условия, объяви переменную до условия и присваивай внутри. Не пытайся лечить ошибку видимости созданием ещё одной одноимённой переменной в случайном месте.

## Разберём бой по шагам

В IntelliJ поставь точку останова слева от строки, где вычисляется урон. Запусти программу через Debug. Используй Step Over, чтобы выполнять по одной строке, и смотри значения `damage`, `enemyHealth`, `heroHealth` в окне переменных. Названия кнопок важнее горячих клавиш: раскладки IDE бывают разные.

Запиши ожидаемые значения на бумаге: атака 18, броня 5, урон 13, здоровье 45 → 32. Затем сравни с тем, что реально происходит. Если отладчик пока мешает, временные `println` с промежуточными значениями тоже подходят.

Что проверить, если не находится Main
{/collapsible}

Файл называется `Main.java`, класс — `Main`, регистр совпадает. Внутри есть `public static void main(String[] args)`. Для этого курса не добавляем строку `package`. В настройках проекта выбран JDK. Запускаем текущий файл, а не старую конфигурацию другого упражнения.

{/collapsible}

Практика: убери точку с запятой после объявления и посмотри ошибку; верни её. Затем намеренно вычти отрицательный урон и поймай логическую ошибку. Главное — после экскурсии вернуть рабочую версию.

Языковая основа: [Oracle: область видимости, JLS §6.3](https://docs.oracle.com/javase/specs/jls/se21/html/jls-6.html#jls-6.3).
