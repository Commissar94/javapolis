# Жив ли гладиатор? Вопрос для boolean

Число здоровья отвечает на вопрос «сколько». Для решения «продолжать бой или нет» нужен ответ `true` либо `false`.

```java
int health = 20;
boolean alive = health > 0;
System.out.println(alive); // true
```

`health > 0` — выражение типа `boolean`. Мы вычислили его один раз и сохранили результат. Если затем изменить здоровье, переменная `alive` сама не пересчитается. Это снова значение, а не вечное заклинание.

| Запись | Вопрос |
|---|---|
| `health > 0` | Больше нуля? |
| `health >= 20` | Не меньше двадцати? |
| `health < 100` | Меньше ста? |
| `health <= 0` | Не больше нуля? |
| `health == 0` | Равно нулю? |
| `health != 0` | Не равно нулю? |

Не перепутай `=` и `==`. Первое присваивает, второе сравнивает. Для сравнения текста позже используем `equals`, а не `==`.

## Несколько условий

- `&&` — **и**: оба условия должны быть истинны.
- `||` — **или**: достаточно хотя бы одного.
- `!` — **не**: переворачивает логическое значение.

```java
int heroHealth = 100;
int enemyHealth = 45;
int potions = 2;
boolean bothAlive = heroHealth > 0 && enemyHealth > 0;
boolean canHeal = heroHealth < 100 && potions > 0;
boolean fightFinished = heroHealth <= 0 || enemyHealth <= 0;
System.out.println(bothAlive);     // true
System.out.println(canHeal);       // false
System.out.println(fightFinished); // false
System.out.println(!fightFinished); // true
```

При `&&` правая часть не вычисляется, если слева уже `false`. При `||` — если слева уже `true`. Это называют коротким замыканием. Операторы `&` и `|` существуют, но для наших условий выбираем именно двойные.

Добавляй скобки вокруг смысловых групп, если смешиваешь несколько операций. Заставлять читателя держать всю таблицу приоритетов в голове — сомнительный подарок будущему себе.

{quiz}
Герой имеет 10 HP, противник — 0 HP. Чему равно heroHealth > 0 && enemyHealth > 0?
- true
+ false
{/quiz}

Практика: проверь условие лечения для трёх случаев: 100 HP и два зелья; 70 HP и одно; 70 HP и ноль. Получится `false`, `true`, `false`. Скоро игра будет по этим ответам выбирать действия.
