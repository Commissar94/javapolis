# Колизей 1: у нас тут свой гладиатор

Хочется написать игру, а тебе опять предлагают посчитать площадь прямоугольника? Прямоугольник, конечно, тоже достойный противник. Но сегодня обойдёмся без него.

Мы сделаем консольную игру: гладиатор выходит на арену, атакует, защищается, лечится и проходит турнир. Графики пока не будет. Будут твой код, понятные правила и кнопка запуска, которая постепенно перестанет пугать.

## Как будем учиться

Сначала несколько коротких глав, затем большая практика. Каждый этап продолжает предыдущий. Не нужно начинать пять несвязанных проектов: мы выращиваем одну игру.

| Этап | Что получится | Что понадобится |
|---|---|---|
| 1. Паспорт гладиатора | Карточка героя в консоли | Литералы, типы, переменные, вывод |
| 2. Первый удар | Урон с учётом брони и ответ противника | Арифметика, сравнения, условия |
| 3. Автоматический бой | Бой до победы с разным уроном | `while`, случайные числа, `break` |
| 4. Ты командуешь | Атака, осторожный удар, лечение, выход | Ввод, строки, проверка команд |
| 5. Турнир | Три соперника, отдых, итоговая статистика | `for`, простые методы, параметры и `return` |

Массивы, коллекции, проектирование классов и многопоточность оставим «Колизею 2». Готовыми `String`, `Scanner` и `Math` пользоваться будем: не обязательно строить собственную кузницу, чтобы взять меч.

## Подготовь арену

Нужны JDK 21 и IntelliJ IDEA с поддержкой Java. Если они ещё не установлены, сначала пройди мини-курс «Получения гражданства». Здесь начинаем с создания проекта:

1. Создай обычный Java-проект `Coliseum`. Для этой игры Maven, Spring и база данных не нужны.
2. Выбери JDK 21. Создай в папке исходников файл `Main.java` без строки `package`.
3. Вставь программу ниже и запусти `main` зелёной кнопкой рядом с ним.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Арена открыта!");
    }
}
```

В консоли должно появиться `Арена открыта!`. Если консоль не видна, открой окно Run. Ура, у игры уже есть релиз. Пока очень скромный.

`Main` — имя класса и файла. `main` — метод, с которого начинается запуск нашей программы. Команды пишем внутри его фигурных скобок. Вся строка `public static void main(String[] args)` пока служит готовой рамкой. `String[] args` действительно обозначает массив аргументов запуска, но использовать его в этом курсе не будем. С методами разберёмся перед турниром; ООП сейчас не требуется.

## Как работать с примерами

Если в блоке нет `public class Main`, это **фрагмент для вставки внутрь `main`**. Фрагменты разных глав запускай отдельно: одинаковые имена переменных нельзя объявлять дважды в одном блоке. Блоки с пометкой «не компилируется» нужны для разбора ошибок.

Большие этапы делай в IDE. Проверка `sum` в браузере предназначена для другой задачи и этот проект не проверяет. В каждом этапе будут требования, контрольные случаи, подсказки и полное решение под раскрывающимся блоком. Сначала попробуй сам, потом сравни. Перепечатать чужой код полезнее, чем ничего, но объяснить свой код ещё полезнее.

Сохраняй рабочую версию перед новым этапом: отдельной копией папки или коммитом, если уже пользуешься Git. Учиться можно без Git, Python и Docker.

Техническая опора курса — [документация Java SE 21](https://docs.oracle.com/en/java/javase/21/) и спецификация языка. Ссылки в главах — для проверки деталей, читать спецификацию целиком перед первым ударом не нужно.
