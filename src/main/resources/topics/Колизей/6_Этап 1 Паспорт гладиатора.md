# Этап 1. Паспорт гладиатора

На арену без регистрации не пускают. Даже если у тебя меч. Особенно если у тебя меч.

**Результат этапа:** программа хранит характеристики героя в переменных и показывает карточку в консоли. Боя пока нет — сначала научимся не путать здоровье с именем.

## Твоя задача

В `Main.java` внутри `main` объяви:

| Имя переменной | Тип | Начальное значение |
|---|---|---|
| `heroName` | `String` | `"Спартак"` |
| `health` | `int` | `100` |
| `attack` | `int` | `18` |
| `armor` | `int` | `5` |
| `gold` | `int` | `0` |
| `rank` | `char` | `'C'` |
| `champion` | `boolean` | `false` |

Выведи карточку. Значения бери из переменных: строка `System.out.println("Здоровье: 100");` показывает нужный текст, но обходит смысл задания.

```text
=== КОЛИЗЕЙ ===
Гладиатор: Спартак
Здоровье: 100
Атака: 18
Броня: 5
Золото: 0
Ранг: C
Чемпион: false
```

Начни с пустого `main` из первой главы. Сначала добавь две переменные и запусти. Затем остальные. Не обязательно писать всё за один заход и только потом знакомиться с двадцатью красными подчёркиваниями.

## Проверь себя

1. С исходными значениями карточка совпадает с образцом.
2. Если изменить `health` на 75, в карточке появится 75. Не переписывай строку вывода.
3. Если сменить имя, меняется имя в карточке.
4. Ты можешь объяснить, почему `rank` в одинарных кавычках, а имя — в двойных.
5. Программа запускается без предупреждения об использовании неинициализированной переменной.

{collapsible="true"}
Подсказка, если пока не получается
{/collapsible}

Для одного поля нужна пара строк: объявление, затем вывод. Например, `int health = 100;` и `System.out.println("Здоровье: " + health);`. Остальные устроены похожим образом. `champion` печатается как `false`, без кавычек в объявлении.

{/collapsible}

## После сравнения с решением

Закрой подсказку и создай карточку второго героя с другим именем, не копируя готовую программу целиком. Затем верни контрольные значения и сохрани рабочую версию как «этап 1».

Золото, ранг и признак чемпиона пока нужны для знакомства с данными. На следующих этапах сосредоточимся на здоровье и бое; не каждую учебную переменную нужно тащить до финала.

**Готово, когда:** ты меняешь характеристики в одном месте и понимаешь, откуда в консоли берётся каждая строка. Теперь можно выдать герою противника.


{collapsible="true"}
Разбор и один из вариантов решения
{/collapsible}

```java
public class Main {
    public static void main(String[] args) {
        String heroName = "Спартак";
        int health = 100;
        int attack = 18;
        int armor = 5;
        int gold = 0;
        char rank = 'C';
        boolean champion = false;

        System.out.println("=== КОЛИЗЕЙ ===");
        System.out.println("Гладиатор: " + heroName);
        System.out.println("Здоровье: " + health);
        System.out.println("Атака: " + attack);
        System.out.println("Броня: " + armor);
        System.out.println("Золото: " + gold);
        System.out.println("Ранг: " + rank);
        System.out.println("Чемпион: " + champion);
    }
}
```

{/collapsible}
