# Этап 2. Первый удар

У нас будет один обмен ударами: герой атакует первым, выживший противник отвечает. Никаких циклов пока не требуется.

**Основа:** продолжи проект этапа 1. Имя сохрани, `health`, `attack`, `armor` переименуй в `heroHealth`, `heroAttack`, `heroArmor`. Вывод полной карточки можно убрать. Числа ниже — новые настройки для проверки именно этого этапа.

## Начальные данные

| Переменная | Значение |
|---|---|
| `heroName` | `"Спартак"` |
| `heroHealth` | `100` |
| `heroAttack` | `18` |
| `heroArmor` | `3` |
| `enemyHealth` | `45` |
| `enemyAttack` | `12` |
| `enemyArmor` | `5` |

## Правила

1. Урон героя равен атаке минус броня врага, но не меньше 1.
2. Вычти урон из здоровья врага. Если результат меньше нуля, сохрани ноль.
3. Выведи нанесённый урон и оставшееся здоровье врага.
4. Только живой враг отвечает по той же формуле: его атака минус броня героя, минимум 1.
5. Здоровье героя тоже не опускается ниже нуля. В конце выведи его; при нуле сообщи о поражении.

Для основных данных получится:

```text
Спартак наносит урон: 13
Здоровье противника: 32
Ответный урон: 9
Здоровье героя: 91
```

## Как собирать

Сначала реализуй удар героя и сравни два числа. Потом добавь ограничение здоровья. Затем оберни ответ врага в `if (enemyHealth > 0)`. Последним добавь сообщение для поверженного врага. Запускай после каждого шага.

{collapsible="true"}
Подсказка к ответному удару
{/collapsible}

Сразу после изменения здоровья врага проверь его новое значение. Переменную `enemyDamage` можно объявить внутри этой ветки: снаружи она не нужна. А `heroHealth` объяви до условия, потому что выводить её нужно в любом случае.

{/collapsible}

## Контрольные случаи

Каждый случай проверяй отдельно, возвращая остальные исходные значения.

| Что изменить | Что должно произойти |
|---|---|
| Ничего | Враг: 32 HP, герой: 91 HP |
| `enemyArmor = 99` | Урон героя 1, враг: 44 HP |
| `enemyHealth = 13` | Враг: 0 HP; ответа нет; герой: 100 HP |
| `enemyHealth = 5` | Враг: 0 HP, а не −8; ответа нет |
| `heroHealth = 4` | После ответа герой: 0 HP, сообщение о поражении |
| `heroArmor = 99` | Ответный урон 1, герой: 99 HP |

**Готово, когда:** все случаи проходят, а ты можешь объяснить, почему проверка смерти стоит до ответного удара. Сохрани этап 2. Следующая остановка — полный бой без копирования одного удара двадцать раз.


{collapsible="true"}
Разбор и один из вариантов решения
{/collapsible}

```java
public class Main {
    public static void main(String[] args) {
        String heroName = "Спартак";
        int heroHealth = 100;
        int heroAttack = 18;
        int heroArmor = 3;
        int enemyHealth = 45;
        int enemyAttack = 12;
        int enemyArmor = 5;

        int damage = heroAttack - enemyArmor;
        if (damage < 1) {
            damage = 1;
        }
        enemyHealth = enemyHealth - damage;
        if (enemyHealth < 0) {
            enemyHealth = 0;
        }
        System.out.println(heroName + " наносит урон: " + damage);
        System.out.println("Здоровье противника: " + enemyHealth);

        if (enemyHealth > 0) {
            int enemyDamage = enemyAttack - heroArmor;
            if (enemyDamage < 1) {
                enemyDamage = 1;
            }
            heroHealth = heroHealth - enemyDamage;
            if (heroHealth < 0) {
                heroHealth = 0;
            }
            System.out.println("Ответный урон: " + enemyDamage);
        } else {
            System.out.println("Противник повержен и не отвечает.");
        }
        System.out.println("Здоровье героя: " + heroHealth);
        if (heroHealth == 0) {
            System.out.println("Герой проиграл.");
        }
    }
}
```

{/collapsible}
