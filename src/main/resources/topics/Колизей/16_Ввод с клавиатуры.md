# Scanner: игрок наконец получает слово

До сих пор мы меняли настройки в исходниках. Теперь программа дождётся команды в консоли.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Как зовут гладиатора?");
        if (scanner.hasNextLine()) {
            String name = scanner.nextLine();
            System.out.println("На арену выходит: " + name);
        } else {
            System.out.println("Ввод завершён.");
        }
        scanner.close();
    }
}
```

Это полная отдельная программа. `import` находится **перед классом**, не внутри `main`. Он позволяет использовать короткое имя готового класса `Scanner`. В строке с `new` создаём средство чтения, а `System.in` обозначает стандартный ввод.

Набери имя в консоли Run и нажми Enter. Без Enter программа обычно продолжает ждать завершения строки. Ожидание ввода — нормальное поведение, не зависание боя.

## Что читаем

`nextLine()` возвращает строку целиком без завершающего перевода строки. Команду `1` мы тоже прочитаем как строку `"1"`. Так `меч`, пустая строка или очень длинное число не вызывают ошибку преобразования в `int`: программа просто проверит, известна ли ей такая команда.

У `Scanner` есть `nextInt()`, но смешивание `nextInt()` и `nextLine()` часто удивляет новичков: числовой метод не забирает оставшийся разделитель строки, и следующее чтение может вернуть пустой остаток. В этом курсе всё меню читаем одним способом — `nextLine()`.

## А если читать больше нечего

`hasNextLine()` сообщает, есть ли следующая строка, не забирая её. Он тоже может ждать ввод. `false` означает конец потока, а не «пользователь задумался на пять секунд». Без проверки вызов `nextLine()` на закончившемся вводе может выбросить исключение.

В игре договоримся: конец ввода равен выходу. В интерактивной консоли обычно проще ввести `0`, чем отправлять системный сигнал окончания ввода.

Один `Scanner` создаём перед игровым циклом. Не создаём новый на каждом ходу. В конце всей программы вызываем `close()`: он закрывает и связанный стандартный ввод, поэтому после этого читать из него больше не пытаемся.

Практика: запусти пример и введи имя с пробелом — `Спартак Младший`. Оно должно сохраниться целиком. Затем отдельным запуском введи пустую строку: программа её прочитает; решать, разрешено ли пустое имя, будет уже наше правило.
