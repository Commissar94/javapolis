# Этап 4. Теперь решения твои

Автобой был репетицией. Теперь герой ждёт твоих команд, а не самостоятельно договаривается с судьбой.

**Основа:** сохрани третий этап и доработай его. Здоровье героя 100, максимум 100, броня 2; здоровье противника теперь 60, броня 3. Его атака остаётся 8–12. Два зелья на весь бой.

## Что должно появиться

- Один `Scanner` до цикла; команды читаются строками и обрабатываются после `trim()`.
- Перед выбором выводятся оба здоровья и количество зелий.
- Работают все действия из предыдущей главы: обычная атака, осторожный удар, лечение, выход.
- Неизвестная команда и недоступное лечение не тратят ход.
- Погибший враг не отвечает. HP не выходят за границы 0–100 для героя и не становятся отрицательными у врага.
- `turns` считает только выполненные игровые действия. Выход и ошибки не считаются.
- Конец ввода завершает бой как выход; программа не падает и не объявляет победу.
- Итог содержит результат боя, число ходов, здоровье и оставшиеся зелья.

Используй `boolean quit = false` до цикла. При выходе меняй его на `true`. После цикла сначала проверяй `quit`, затем смерть героя, затем победу. Выживший герой, который вышел, ещё не чемпион.

## Порядок сборки

Сначала подключи только команды `1` и `0`. Потом добавь обработку неизвестной строки. Затем осторожный удар. Лечение добавляй последним: в нём больше проверок. После каждого шага сыграй маленький бой.

Все ошибки заканчиваются `continue`, выход — `break`. Если увеличить `turns` после этих веток, счётчик увидит только выполненные действия. После лечения оставляй `attack` нулевой и не запускай расчёт урона героя.

## Контрольные сценарии

Каждая строка в колонке «ввод» — отдельная команда с Enter. Каждый сценарий начинай новым запуском.

| Ввод | Что проверить |
|---|---|
| `0` | Выход; 0 ходов, 100 HP, 2 зелья |
| `меч`, пустая строка, `0` | Две ошибки; состояние не изменилось |
| `3`, `0` | Полное здоровье: зелье не потрачено, 0 ходов |
| ` 1 `, `0` | Пробелы допустимы; один ход, здоровье 90–94 |
| `2`, `0` | Враг теряет 3 HP; герой теряет 1–4 HP |
| `1`, `3`, `0` | Два хода, осталось одно зелье; герой вылечился до 100 перед вторым ответом |
| `1`, `3`, `3`, `3`, `0` | Третье лечение недоступно, всего 3 хода, зелий 0 |
| Только `1` до конца | Победа; после последнего удара нет ответа |

Ещё проверь последовательность `2`, `1`, `0`: защита должна действовать только на первый ответ, второй снимает 6–10 HP. Для проверки поражения временно поставь герою 1 HP и выбери `1`. Для проверки ограничения лечения временно убери разброс и проследи, что HP сначала ограничиваются сотней, а затем уменьшаются от ответа.

**Готово, когда:** ты можешь провести бой через консоль, ошибиться в команде без наказания, выйти и получить честный итог. Сохрани этап 4. Осталось превратить отдельный бой в турнир.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int maxHealth = 100;
        int heroHealth = maxHealth;
        int heroArmor = 2;
        int enemyHealth = 60;
        int enemyArmor = 3;
        int potions = 2;
        int turns = 0;
        boolean quit = false;

        while (heroHealth > 0 && enemyHealth > 0) {
            System.out.println("Герой: " + heroHealth + ", противник: " + enemyHealth
                    + ", зелий: " + potions);
            System.out.println("1 — атака, 2 — осторожный удар, 3 — лечение, 0 — выход");
            if (!scanner.hasNextLine()) {
                quit = true;
                break;
            }
            String action = scanner.nextLine().trim();
            boolean guarding = false;
            int attack = 0;

            if (action.equals("0")) {
                quit = true;
                break;
            } else if (action.equals("1")) {
                attack = 12 + (int) (Math.random() * 7);
            } else if (action.equals("2")) {
                attack = 6;
                guarding = true;
            } else if (action.equals("3")) {
                if (potions == 0 || heroHealth == maxHealth) {
                    System.out.println("Лечение недоступно. Ход не потрачен.");
                    continue;
                }
                heroHealth = Math.min(maxHealth, heroHealth + 20);
                potions--;
                System.out.println("Здоровье после лечения: " + heroHealth);
            } else {
                System.out.println("Нет такой команды. Ход не потрачен.");
                continue;
            }

            turns++;
            if (attack > 0) {
                int damage = Math.max(1, attack - enemyArmor);
                enemyHealth = Math.max(0, enemyHealth - damage);
                System.out.println("Урон героя: " + damage);
                System.out.println("Здоровье противника: " + enemyHealth);
            }
            if (enemyHealth == 0) {
                break;
            }

            int defense = heroArmor;
            if (guarding) {
                defense = defense + 6;
            }
            int enemyAttack = 8 + (int) (Math.random() * 5);
            int enemyDamage = Math.max(1, enemyAttack - defense);
            heroHealth = Math.max(0, heroHealth - enemyDamage);
            System.out.println("Урон противника: " + enemyDamage);
        }

        if (quit) {
            System.out.println("Выход из боя.");
        } else if (heroHealth == 0) {
            System.out.println("Поражение.");
        } else {
            System.out.println("Победа!");
        }
        System.out.println("Ходов: " + turns);
        System.out.println("Итоговое здоровье: " + heroHealth);
        System.out.println("Осталось зелий: " + potions);
        scanner.close();
    }
}
```
