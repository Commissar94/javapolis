# Один ход — одно решение

Добавить три кнопки несложно. Сложнее договориться, что они делают. Сначала фиксируем правила, иначе код будет честно выполнять то, что мы сами не до конца придумали.

| Команда | Действие героя | Ответ противника |
|---|---|---|
| `1` | Атака 12–18 до брони | Обычный, если противник выжил |
| `2` | Осторожный удар: атака 6 до брони | Броня героя увеличена на 6 только для этого ответа |
| `3` | Восстановить до 20 HP, потратить одно зелье | Обычный ответ; лечение занимает ход |
| `0` | Выйти из боя | Нет |
| Другая строка | Сообщить об ошибке и спросить снова | Нет |

Если зелий нет или здоровье полное, лечение недоступно: зелье и ход не расходуются, враг не отвечает. Лечение не делает героя бессмертным: после восстановления враг всё ещё может его добить.

## Ограничиваем числа

Мы уже писали `if`, чтобы не уходить ниже нуля. У готового класса `Math` есть удобные методы: `max(a, b)` возвращает большее из двух значений, `min(a, b)` — меньшее.

```java
int attack = 4;
int armor = 9;
int damage = Math.max(1, attack - armor);
int health = Math.max(0, 7 - damage);
int healedHealth = Math.min(100, 90 + 20);
System.out.println(damage);       // 1
System.out.println(health);       // 6
System.out.println(healedHealth); // 100
```

Передаём методы значения через запятую; они возвращают число. Запись короче знакомого условия, правило игры то же самое. Лечение ограничивается максимумом: при 90 HP зелье восстановит фактически 10, но всё равно потратится одно целое зелье.

## Защита живёт один ход

В начале каждого прохода цикла создавай `boolean guarding = false;` и `int attack = 0;`. При осторожном ударе выставляй `guarding = true`. При лечении `attack` останется нулевой: это признак отсутствия удара, а не удар на один урон.

Поэтому вычитание брони врага делаем только при `attack > 0`. Иначе правило минимального урона случайно превратит лечение в дополнительную атаку.

Для ответа врага бери `defense = heroArmor`; если есть защита, прибавь к локальной `defense` шесть. Саму постоянную `heroArmor` не изменяй. Так бонус закончится вместе с ходом.

Практика на бумаге: при броне героя 2 и атаке врага 8 обычный ответ снимает 6 HP, а под защитой — 1 HP, потому что минимум урона по-прежнему действует. При HP 95 лечение сначала поднимет здоровье до 100, затем обычный ответ уменьшит его.

Методы: [Oracle: Math.min и Math.max](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Math.html#max(int,int)).
