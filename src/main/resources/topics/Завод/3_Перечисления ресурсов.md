# Перечисления ресурсов

У нас три ресурса: руда, слиток и пластина. Можно хранить их названия строками. Тогда однажды на складе появится `"irno"`, а бухгалтер заведёт четвёртую колонку. Компилятор к такой строке претензий не имеет.

Для заранее известного набора значений есть `enum` — перечисление. В шаблоне уже создан файл `model/Resource.java`:

```java
package javapolis.factory.model;

public enum Resource {
    ORE, INGOT, PLATE
}
```

`Resource.ORE` — конкретное значение типа `Resource`. Константы обычно пишут заглавными буквами. Метод, который принимает `Resource`, не примет строку `"ORE"` или значение другого перечисления. Опечатку в имени константы IDE заметит до запуска.

## Используем значение

Этот пример запускается отдельным файлом `Main.java`:

```java
enum Product {
    ORE, INGOT, PLATE
}

public class Main {
    public static void main(String[] args) {
        Product product = Product.INGOT;
        if (product == Product.INGOT) {
            System.out.println("Отправляем на пресс");
        }
    }
}
```

Для значений одного `enum` удобно использовать `==`: каждая константа обозначает один экземпляр. Правило сравнения строк из Колизея никуда не исчезло — для строк по-прежнему обычно нужен `equals`.

Переменная ссылочного типа может содержать `null`, то есть не указывать на объект. Это не четвёртый ресурс. В методах склада договоримся отклонять `null` и возвращать `false`. Проверка `resource == null` не вызывает методы у отсутствующего объекта.

## Не смешиваем разные понятия

В `Resource` описано **что перевозим**, в `MachineType` — **какое здание**, в `Status` — **что сейчас происходит**. Шахта может иметь тип `MINE`, статус `OUTPUT_FULL` и запас ресурса `ORE`. Это три разных свойства.

В готовом складе стоит `new EnumMap<>(Resource.class)`. Это реализация `Map` для ключей одного enum-типа. `Resource.class` сообщает ей тип ключей. Пустая карта не содержит запасов: `count` возвращает 0 для отсутствующего ресурса. Сама `EnumMap` не проверяет вместимость склада — это твоя задача.

**Проверь себя:** почему `MachineType.MINE` нельзя передать в `add(Resource resource, int amount)`? Что лучше использовать для имени завода, которое вводит игрок: `String` или `enum`?

Устройство перечислений описано у [Oracle: Enum Types](https://docs.oracle.com/javase/tutorial/java/javaOO/enum.html), а ограничения ключей — в [API EnumMap для Java 21](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/EnumMap.html).
