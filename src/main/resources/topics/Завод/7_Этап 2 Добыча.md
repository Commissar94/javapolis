# Этап 2. Шахта выходит на смену

Склад научился считать. Пора перестать возить руду вручную. Реализуй `tick(Machine machine)` в `student/Mining.java`.

Один вызов добывает **одну руду**, если шахта включена и на выходе есть место. Никаких случайных бонусов: сначала добьёмся понятного поведения.

## Алгоритм

1. Если `machine.isEnabled()` вернул `false`, поставь `Status.PAUSED` и заверши метод.
2. Попытайся добавить `Resource.ORE` в `machine.getOutput()` через свой `Inventory.add`.
3. Если места нет, поставь `Status.OUTPUT_FULL`. Счётчик добычи не увеличивай.
4. При успехе увеличь `machine.getProduced()` на один через `addProduced(1)` и поставь `Status.WORKING`.

Счётчик `produced` — сколько шахта изготовила за смену. Это не текущий запас: часть руды могла уехать. Храни состояние в переданном `Machine`; второй шахте нужны собственные числа.

## Проверяем

Запусти `./mvnw -Pstage-2 test` или `.\mvnw.cmd -Pstage-2 test`. Этап зависит от уже работающего склада.

Перезапусти обычную игру. После первого шага на выходе шахты будет 1 руда. После второго в плавильне появится первая руда, а шахта добудет следующую. Пока плавка не реализована, вход плавильни будет заполняться.

Останови производство у шахты, затем сделай несколько шагов. Новая руда не появляется, однако конвейер может забрать накопленную. Включи её обратно — добыча возобновится. Для проверки заполнения убери конвейер: выход шахты вмещает 24 единицы; следующая добыча должна остановиться без потери руды.

{collapsible="true"}
Подсказка
{/collapsible}

Результат `add` уже отвечает на вопрос «поместилась ли руда?». Не увеличивай `produced`, пока не получил `true`. Запись `machine.getOutput().add(...)` сначала получает объект склада, затем вызывает его метод.

{/collapsible}

**Готово, когда:** шахта работает, объясняет паузу и заполненный выход, а две шахты не делят состояние. Сохрани версию «добыча».

{collapsible="true"}
Разбор и полный файл решения
{/collapsible}

```java
package javapolis.factory.student;

import javapolis.factory.model.Machine;
import javapolis.factory.model.Resource;
import javapolis.factory.model.Status;

/** Stage 2. A running mine produces one ore per logical tick. */
public final class Mining {
    public void tick(Machine machine) {
        if (!machine.isEnabled()) {
            machine.setStatus(Status.PAUSED);
            return;
        }
        if (!machine.getOutput().add(Resource.ORE, 1)) {
            machine.setStatus(Status.OUTPUT_FULL);
            return;
        }
        machine.addProduced(1);
        machine.setStatus(Status.WORKING);
    }
}
```

Шахта доверяет складу проверку вместимости. Счётчик выпуска растёт только после успешного добавления, а состояние принадлежит переданному зданию.

{/collapsible}
