# Композиция и ссылки

У станка есть входной склад и выходной склад. Это уже знакомые объекты `Inventory`. Мы собираем сложный объект из других объектов — используем композицию.

Не нужно учить склад плавить металл, а плавильню — заново считать свободные места. Каждый класс отвечает за свою часть работы.

## Что находится в переменной

Переменная типа `Inventory` хранит ссылку на объект. При присваивании копируется ссылка; второй склад сам собой не создаётся.

Этот фрагмент можно выполнить внутри метода, где доступны классы игрового проекта:

```java
Inventory first = new Inventory(10);
Inventory same = first;
same.add(Resource.ORE, 3);
System.out.println(first.count(Resource.ORE)); // 3

Inventory other = new Inventory(10);
System.out.println(other.count(Resource.ORE)); // 0
```

`first` и `same` обращаются к одному складу. `other` указывает на отдельный объект. Чтобы создать объект, нужен `new`, а не просто ещё одна переменная.

Java передаёт аргументы **по значению**. Для объекта это значение ссылки. Метод получает копию ссылки и может изменить общий объект через неё. Если внутри метода присвоить параметру новый склад, переменная вызывающего кода не начнёт указывать на этот новый объект.

## Как это устроено в заводе

`Machine` создаёт два разных `Inventory`. `getInput()` возвращает вход, `getOutput()` — выход. Когда `Processing` получает склад и вызывает `remove`, меняется склад именно этого станка.

Поэтому в `tick` не надо каждый раз создавать `new Inventory(...)`: такой склад будет пустым и не связанным с картой. Нужно работать с объектами, которые уже входят в переданную машину.

`Recipe` описывает требования: вид и количество входного ресурса, выходного ресурса и число тактов. Он не хранит прогресс конкретной плавильни. Один рецепт можно использовать у двух станков; у каждого останутся собственные запасы и прогресс.

## Распределяем обязанности

| Объект | Отвечает за |
|---|---|
| `Inventory` | Количество, место и целую операцию приёма/выдачи |
| `Machine` | Собственные склады, включение, прогресс, счётчик выпуска |
| `Recipe` | Неизменяемые параметры одной партии |
| `Processing` | Переход станка на следующий такт |
| `FactoryEngine` | Вызовы, конвейеры и взаимодействие с готовой страницей |

Наследование для этой задачи не требуется. Связь «станок содержит склад» уже выражает нужный смысл.
