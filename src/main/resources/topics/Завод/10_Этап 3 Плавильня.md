# Этап 3. Первый слиток

Руда уже едет. Теперь реализуй `tick(Machine machine, Recipe recipe)` в `student/Processing.java`, следуя порядку из предыдущей главы.

У `Recipe` доступны `getInput`, `getInputAmount`, `getOutput`, `getOutputAmount`, `getDuration`. У `Machine` — `getInput`, `getOutput`, `getProgress`, `setProgress`, `getProduced`, `addProduced`, `isEnabled`, `setStatus`.

Имена `getInput()` у разных классов означают разные вещи: у машины это склад, у рецепта — вид ресурса. Следи за типами; IDE покажет их при наведении.

## Условия задачи

Реализуй проверки выключения, отсутствия рецепта, нехватки входа и места на выходе. Они не меняют запасы и прогресс. Затем продвинь прогресс на один. При достижении длительности выпусти ровно одну партию и обнули прогресс.

Бери **все числа и ресурсы из `recipe`**. Не зашивай `ORE`, `INGOT` и длительность 2 в алгоритм. Сегодня он управляет плавильней, скоро ему дадут пресс. Отдельный класс обработки для каждого здания нам не понадобится.

## Проверяем

Команда: `./mvnw -Pstage-3 test`, на Windows `.\mvnw.cmd -Pstage-3 test`. Здесь проверяется и рецепт с другими числами: это проверка работы алгоритма, а не знание будущего задания.

Перезапусти игру с чистой песочницей и шагай вручную:

| Такт | Ожидаемое событие |
|---|---|
| 1 | Шахта добыла первую руду |
| 2 | Руда пришла в плавильню; прогресс стал 1 |
| 3 | Плавильня выпустила первый слиток |
| 4 | Слиток приехал на стартовый склад №3 |

Отключи конвейер плавильня → склад и продолжай. Когда выход заполнится, сырьё должно перестать расходоваться. Верни связь — производство оживёт. Проверь остановку при прогрессе 1: после включения нужен ещё один рабочий такт, а не два.

{collapsible="true"}
Подсказка
{/collapsible}

Сохрани вход и выход в локальные переменные `Inventory input` и `Inventory output`, чтобы не писать длинные цепочки. Сначала все ранние `return`, затем увеличение прогресса. Завершение партии удобно поместить в один `if (machine.getProgress() >= recipe.getDuration())`.

{/collapsible}

**Готово, когда:** слитки доезжают до склада, пауза сохраняет прогресс, полный выход не съедает сырьё, тесты зелёные. Сохрани версию «плавильня».

{collapsible="true"}
Разбор и полный файл решения
{/collapsible}

```java
package javapolis.factory.student;

import javapolis.factory.model.Machine;
import javapolis.factory.model.Recipe;
import javapolis.factory.model.Status;

/** Stage 3. Ingredients stay at the input until a whole batch finishes. */
public final class Processing {
    public void tick(Machine machine, Recipe recipe) {
        if (!machine.isEnabled()) {
            machine.setStatus(Status.PAUSED);
            return;
        }
        if (recipe == null) {
            machine.setStatus(Status.NO_RECIPE);
            return;
        }
        if (machine.getInput().count(recipe.getInput()) < recipe.getInputAmount()) {
            machine.setStatus(Status.NO_INPUT);
            return;
        }
        if (machine.getOutput().freeSpace() < recipe.getOutputAmount()) {
            machine.setStatus(Status.OUTPUT_FULL);
            return;
        }
        machine.setProgress(machine.getProgress() + 1);
        machine.setStatus(Status.WORKING);
        if (machine.getProgress() >= recipe.getDuration()) {
            machine.getInput().remove(recipe.getInput(), recipe.getInputAmount());
            machine.getOutput().add(recipe.getOutput(), recipe.getOutputAmount());
            machine.addProduced(recipe.getOutputAmount());
            machine.setProgress(0);
        }
    }
}
```

Все параметры берутся из рецепта. До завершения партии вход не расходуется. Ранние выходы сохраняют прогресс, поэтому пауза не начинает партию заново.
