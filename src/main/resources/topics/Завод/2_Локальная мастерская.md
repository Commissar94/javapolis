# Локальная мастерская

Завод живёт на твоём компьютере. Аккаунт JavaPolis, сервер преподавателя и база данных для запуска не нужны. Java считает ресурсы, страница показывает состояние и отправляет команды.

## Первый запуск

Нужен **JDK 21**. Команда `java -version` должна показать версию 21. Открой в IDE отдельный Maven-проект `courses/factory/starter`, а не корневой проект сайта. В раздаваемом архиве эта папка называется `factory-player`.

В терминале перейди в папку, где лежат `pom.xml` и `mvnw`. На Windows используй PowerShell:

```powershell
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

На Linux и macOS:

```bash
chmod +x mvnw
./mvnw test
./mvnw spring-boot:run
```

Wrapper скачает Maven, Maven скачает зависимости. Для первой сборки нужен интернет; Node.js не требуется. Дождись сообщения о запуске Tomcat и открой [локальный завод](http://127.0.0.1:8081). Остановка приложения — `Ctrl+C` в терминале.

Обычный `test` проверяет готовую оболочку. Он **не означает**, что ты решил задания. Тесты этапов включаются отдельно: `./mvnw -Pstage-1 test`. В исходном шаблоне такие тесты должны падать: методы пока не реализованы.

## Где писать

Открой `src/main/java/javapolis/factory/student`. Здесь пять файлов с пометками `TODO`: `Inventory`, `Mining`, `Processing`, `Recipes`, `Contract`. Сигнатуры методов и готовые вспомогательные методы сохраняем. Новый `Main` не нужен.

В `model` лежат здания, ресурсы и рецепты. В `runtime` — часы, конвейеры и команды. Их можно читать, но для прохождения изменять не требуется. После правки кода останови и снова запусти приложение: простое обновление страницы Java-код не пересобирает.

Для знакомства с конечным результатом можно отдельно запустить `./mvnw -Psolution spring-boot:run`. В Windows: `.\mvnw.cmd -Psolution spring-boot:run`. Плашка **«Эталон»** показывает этот режим. Затем останови его и вернись к обычному запуску с плашкой **«Мой код»**. Эталон собирается в отдельной папке и не заменяет твои исходники.

## Управление

Выбери здание — справа появятся его запасы и состояние. «Шаг» выполняет один такт и ставит игру на паузу. «Запустить» включает часы. Скорость меняет число тактов за обновление, а не рецепт.

Для стройки выбери тип здания внизу карты и свободную клетку. Для конвейера выбери источник, нажми «Провести конвейер», затем получателя. Крестик у связи удаляет конвейер. `Esc` отменяет инструмент. Стартовые три здания защищены от демонтажа; новое можно убрать только пустым и без незавершённой партии.

«Новая смена» предлагает песочницу или контракт и сбрасывает завод. В песочнице есть учебная поставка руды; в контракте её нет. Изменение кода тоже требует новой проверки с чистого состояния.

## Перед складом

Прочитай существующую главу [«Классы и объекты»](/university/classes). В [«Коллекциях»](/university/advanced/collections) пока нужны разделы `Map`, `For-each` и «Map в заводском складе». Stream API, сортировку и большой пример со студентами можно оставить на потом.

Если порт занят, останови предыдущий запуск. Для другого порта: `./mvnw spring-boot:run -Dspring-boot.run.arguments=--server.port=8082`, затем открой адрес с 8082. Если Maven сообщает о неправильной версии Java, проверь JDK проекта в IDE и `JAVA_HOME`: это должны быть установки JDK 21.
