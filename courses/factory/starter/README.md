# Завод 1 — мастерская игрока

Локальная мини-игра на **Java 21 и Spring Boot**. Готовая страница показывает здания, конвейеры и ресурсы; ты реализуешь производство в пяти Java-классах. Аккаунт JavaPolis, база данных и Node.js не нужны.

## Начать

Установи JDK 21. Открой **эту папку** как Maven-проект в IDE. Команды выполняются здесь, рядом с `pom.xml`. Первый запуск скачивает Maven и зависимости, поэтому нужен интернет.

Windows, PowerShell:

```powershell
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

Linux / macOS:

```bash
chmod +x mvnw
./mvnw test
./mvnw spring-boot:run
```

Открой **http://127.0.0.1:8081**. Остановка — `Ctrl+C`. После изменения Java-кода останови приложение и запусти заново. Запасы, постройки и время хранятся в памяти и сбрасываются при перезапуске или выборе новой смены.

В исходном шаблоне завод запускается, но производственные методы помечены `TODO`: их предстоит написать. Обычный `test` проверяет готовую оболочку, **не прохождение курса**.

## Пять заданий

Пиши в `src/main/java/javapolis/factory/student`. Оставь имена классов, пакеты и сигнатуры методов. Каждый этап опирается на предыдущие.

| Этап | Файл | Результат | Проверка |
|---|---|---|---|
| 1 | `Inventory.java` | Приём и выдача с общей вместимостью | `./mvnw -Pstage-1 test` |
| 2 | `Mining.java` | Руда за такт, пауза, полный выход | `./mvnw -Pstage-2 test` |
| 3 | `Processing.java` | Партия по рецепту, ожидание и прогресс | `./mvnw -Pstage-3 test` |
| 4 | `Recipes.java` | Пресс: 3 слитка → 2 пластины за 3 такта | `./mvnw -Pstage-4 test` |
| 5 | `Contract.java` | Доставка 40 пластин до такта 100 включительно | `./mvnw -Pstage-5 test` |

В PowerShell в этих командах замени `./mvnw` на `.\mvnw.cmd`. Тесты этапов в пустом шаблоне падают намеренно. На финише запускай `./mvnw -Pall-stages test`: должны пройти все задания **на твоём коде**.

Полные главы находятся в `lessons/Завод` раздаваемого архива; начать можно с `lessons/README.md`. В репозитории они лежат в `src/main/resources/topics/Завод` от корня JavaPolis. Папки `model` и `runtime`, HTML/CSS/JavaScript — готовая оболочка; её изменение для заданий не требуется.

## Управление

- «Шаг» продвигает один такт и ставит часы на паузу; «Запустить» включает автоматические такты.
- Выбери здание: справа видны вход, выход, рецепт и причина ожидания.
- Выбери тип постройки снизу карты и свободную клетку. `Esc` отменяет инструмент.
- Выбери источник → «Провести конвейер» → здание-получатель. Крестик в списке удаляет связь.
- В песочнице доступна учебная поставка 3 руды во вход плавильни или склад. В контракте внешних поставок нет.
- Стартовые здания нельзя снести. Дополнительное можно демонтировать пустым, с нулевым прогрессом; стоимость вернётся.
- «Новая смена» сбрасывает постройки, ресурсы, бюджет и время. Java-код сохраняется.

Начальная цепочка: шахта №1 → плавильня №2 → склад №3. Для пластин построй пресс, убери связь №2 → №3 и подключи плавильню → пресс → склад. Для контракта в срок понадобится дополнительная плавильня; бюджет на стройку — 300.

В начале такта конвейеры перемещают существующую продукцию, затем станки работают. Один конвейер переносит максимум один предмет за такт. Вход и выход у станка независимы и вмещают по 24 единицы; склад вмещает 200. Пауза здания останавливает производство, но не вывоз готовой продукции. Партия списывает сырьё только при завершении.

## Посмотреть эталон

```bash
./mvnw -Psolution spring-boot:run
./mvnw -Psolution test
```

Останови обычное приложение перед запуском эталона. На странице будет плашка **«Эталон»**. Этот профиль копирует готовые решения из `solutions` в отдельный каталог `target/solution`; твои исходники не изменяются. Для продолжения курса останови эталон и запусти без профиля: `./mvnw spring-boot:run`, плашка **«Мой код»**.

Проверки эталона не доказывают, что ты решил задания. Не комбинируй `solution` с профилями этапов, когда проверяешь свою работу.

## Если не запускается

Проверь `java -version`, JDK проекта в IDE и `JAVA_HOME`: нужен JDK 21. Если порт 8081 занят, останови предыдущий запуск. Другой порт: `./mvnw spring-boot:run -Dspring-boot.run.arguments=--server.port=8082`. Открой соответствующий адрес.

Приложение слушает только `127.0.0.1`. Для курса не нужно открывать его в интернет. Сохранений между запусками, многопользовательского режима и базы данных в первой части нет.
