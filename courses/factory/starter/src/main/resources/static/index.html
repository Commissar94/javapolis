    ТВОЯ МАСТЕРСКАЯ

    Пять шагов до работающего завода

    Меняй классы в src/main/java/javapolis/factory/student, проверяй этап и перезапускай приложение. Графика и сервер уже готовы.

    01

    Склад, который держит слово

    Inventory.java — добавление и списание ресурсов. Выбери плавильню и нажми «Учебная поставка».

    ./mvnw -Pstage-1 test
    02

    Первая руда

    Mining.java — одна руда за такт, пауза и полный выход.

    ./mvnw -Pstage-2 test
    03

    Разжигаем плавильню

    Processing.java — рецепт, ожидание сырья и завершение партии.

    ./mvnw -Pstage-3 test
    04

    Рецепт вместо копипасты

    Recipes.java — добавь пресс: 3 слитка → 2 пластины за 3 такта.

    ./mvnw -Pstage-4 test
    05

    Первый контракт

    Contract.java — сдай 40 пластин до 100-го такта. Одной плавильни мало — перестрой линию.

    ./mvnw -Pstage-5 test
    В Windows используй mvnw.cmd вместо ./mvnw. Зелёный обычный test проверяет обвязку; для своих заданий выбирай профиль этапа. Полный курс — в папке lessons скачанного архива.

    Хочешь сначала увидеть готовый завод? Останови приложение и запусти ./mvnw -Psolution spring-boot:run. На экране появится метка «Эталон». Вернись к своей версии командой ./mvnw spring-boot:run.

    Новая смена

    Карта, запасы и время сбросятся. Твой Java-код останется на месте.
