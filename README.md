# Javapolis - Игровая платформа для изучения Java

## 🎯 О проекте

Javapolis - это инновационная веб-платформа, которая превращает изучение Java программирования в увлекательное игровое приключение. Платформа сочетает в себе лучшие практики обучения с элементами геймификации.

## 🏗️ Структура сайта

### 📱 Страницы

1. **`/landing.html`** - Главная страница (лэндинг)
   - Hero-секция с описанием проекта
   - Особенности платформы
   - Как это работает
   - Призыв к действию

2. **`/`** - Страница входа в систему
   - Форма авторизации
   - Ссылки на регистрацию и лэндинг
   - Автоматическое скрытие элементов для авторизованных пользователей

3. **`/register.html`** - Страница регистрации
   - Форма создания аккаунта
   - Валидация данных
   - Ссылки на вход и лэндинг

4. **`/dashboard.html`** - Панель управления (только для авторизованных)
   - Приветствие пользователя
   - Статистика обучения
   - Навигация по системе

5. **`/city.html`** - Виртуальный город (только для авторизованных)
   - Интерактивные здания для обучения
   - Различные типы активностей
   - Навигация по городу

### 🔐 Система аутентификации

- **Авторизованные пользователи** автоматически перенаправляются на dashboard
- **Неавторизованные пользователи** видят лэндинг и формы входа/регистрации
- **Автоматическое скрытие** ненужных элементов интерфейса

## 🚀 Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Spring Boot 3, Java 17
- **База данных**: H2 (в памяти)
- **Безопасность**: Spring Security
- **Email**: Spring Mail с HTML шаблонами

## 📁 Структура проекта

```
src/main/
├── java/javapolis/
│   ├── config/          # Конфигурация Spring
│   ├── controller/      # REST контроллеры
│   ├── model/          # Модели данных
│   ├── repository/     # JPA репозитории
│   └── service/        # Бизнес-логика
└── resources/
    ├── static/         # HTML страницы
    ├── templates/      # Thymeleaf шаблоны
    └── email-templates/ # Email шаблоны
```

## 🔄 Поток пользователя

1. **Новый пользователь** → Лэндинг → Регистрация → Подтверждение email → Dashboard
2. **Существующий пользователь** → Лэндинг → Вход → Dashboard
3. **Авторизованный пользователь** → Автоматический редирект на Dashboard

## 🚀 Запуск проекта

1. Убедитесь, что у вас установлена Java 17+
2. Клонируйте репозиторий
3. Запустите `mvn spring-boot:run`
4. Откройте `http://localhost:8080`
